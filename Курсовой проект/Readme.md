# Курсовой проект

**Тема:** Разработка программного обеспечения для микроконтроллера TMS320F28335

**Цель:** освоение принципов программирования микроконтроллера TMS320F28335, работы с портами ввода-вывода, модулями последовательного интерфейса SCI и аппаратными таймерами, а также разработки структурированного программного обеспечения для встраиваемых систем электротехнических комплексов.

## 1. Введение

В данной курсовой работе студенты разрабатывают программное обеспечение для отладочной платы на базе микроконтроллера **Texas Instruments TMS320F28335**. Основные задачи:

- организация обмена данными по UART через периферию SCI;
- управление светодиодами на плате по управляющим сигналам;
- отработка навыков работы с регистрами, портами ввода-вывода и периферийными интерфейсами.

## 2. Схема отладочной платы

Для разработки использовать схему отладочной платы:
[📄 Схема платы TMS320F28335 (PDF)](<../Литература%20TMS320F28335/DSP28335_Green_board.pdf>)

## 3. Общие требования к проекту

1. Разработать проект в **Code Composer Studio**.
2. Реализовать взаимодействие с периферией микроконтроллера в соответствии с полученным вариантом.
3. Для разработки использовать язык **C/C++**.
4. Исходный код должен быть структурирован:
   - `main.cpp` — точка входа;
   - **Все аппаратные сущности** (светодиоды, кнопки, SCI, таймеры, и пр.) должны быть реализованы через **классы** или **структуры**;
   - Каждый класс должен полностью реализовывать работу с конкретным периферийным модулем и предоставлять удобный интерфейс для его использования;
   - Методы классов должны предоставлять понятный интерфейс для управления устройством;
   - Код в `main.cpp` должен состоять только из логики работы и вызовов методов классов.
5. Временные интервалы и мигание светодиодов должны реализовываться с использованием указанного в варианте CPU Timer.
6. Нажатием кнопки в каждом варианте считать именно фронт нажатия, а не удержание.
7. Каждый вариант предполагает передачу и приём данных по UART. Поскольку для выполнения работы используется одна отладочная плата, обмен данными между двумя физическими устройствами не осуществляется. Для проверки передачи и приёма необходимо включить внутренний режим loopback выбранного модуля SCI, установив бит `LOOPBKENA` регистра `SCICCR`. В этом режиме передаваемые данные поступают на приёмник того же модуля SCI без физического соединения выводов Tx и Rx.
8. Логика работы должна быть протестирована на реальном оборудовании.
9. В отчёте должны быть отражены:
   - постановка задачи;
   - описание алгоритмов;
   - листинги программ;
   - результаты тестирования.

## 4. Варианты заданий

---

**Вариант 1:**

Реализовать управление светодиодом *`Led2`* следующим образом:

K1 циклически выбирает частоту 1, 2, 4 или 8 Гц. Значение частоты передаётся по SCI вместе с нажатием K1. Приёмник изменяет период мигания Led2 в соответствии с полученной частотой. Нажатие K2 блокирует/разблокирует передачу сообщений по SCI.

<u>Параметры SCI:</u>

Порт SCI: A
Скорость: 38400 бод,
Количество бит данных: 8,
Стоп-бит: 1,
Бит чётности: even;
Таймер: CPU Timer0

---

**Вариант 2:**

Каждые 250 мс формировать новое значение счётчика от 0 до 255 и передавать его по SCI. Значение счётчика увеличивается на единицу каждые 250 мс, а после 255 переходит к 0. Приёмник переключает Led1 для чётного значения и Led2 для нечётного. Нажатие K1 запускает передачу, K2 останавливает её. Переполнение счётчика должно обрабатываться корректно.

<u>Параметры SCI:</u>

Порт SCI: A
Скорость: 19200 бод,
Количество бит данных: 8,
Стоп-бит: 1,
Бит чётности: odd;
Таймер: CPU Timer1

---

**Вариант 3:**

Реализовать пакет из двух байт: код команды, параметр. Код команды определяет, каким светодиодом будет управление Led1/Led2, параметр задаёт число миганий. Период мигания неизменный и равен 1 секунде. Приёмник должен дождаться всего пакета и проверить его корректность до исполнения. При неизвестном коде команда игнорируется. Отправка пакета формируется нажанием K1, выбор количества миганий от 1 до 5 нажанием кнопки K2. Код команды для Led1 - 0xF0, для Led2 - 0x15. При каждой отправке нового пакета код команды чередуется между 0xF0 и 0x15, начиная с 0xF0

<u>Параметры SCI:</u>

Порт SCI: A
Скорость: 9600 бод,
Количество бит данных: 8,
Стоп-бит: 1,
Бит чётности: odd;
Таймер: CPU Timer2

---

**Вариант 4:**

Реализовать три режима работы светодиодов: мигание Led1 при выключенном Led2, мигание Led2 при выключенном Led1, мигание обоих светодиодов. Нажатие K1 переключает режим. Нажатие K2 инициализирует отправку номера режима работы по SCI. Принятая команда устанавливает режим работы. Период мигания светодиодов 1 секунда, скважность 50%. Команды для режимов в десятичном виде следующие:

* Режим 1 - 1
* Режим 2 - 2
* Режим 3 - 3

<u>Параметры SCI:</u>

Порт SCI: B
Скорость: 2400 бод,
Количество бит данных: 3,
Стоп-бит: 1,
Бит чётности: odd;
Таймер: CPU Timer0

---

**Вариант 5:**

Нажатие K1 увеличивает число миганий от 1 до 10. K2 передаёт выбранное значение. После приёма программа запускает мигание Led2 заданное количество раз. Период мигания — 1 с, время включения — 300 мс. Новая команда немедленно отменяет текущую последовательность и запускает новую с начала.

<u>Параметры SCI:</u>

Порт SCI: B
Скорость: 9600 бод,
Количество бит данных: 4,
Стоп-бит: 1,
Бит чётности: even;
Таймер: CPU Timer1

---

**Вариант 6:**

Каждые 200 мс генерировать условное измеряемое датчиком значение в диапазоне 0–100 и передавать его по SCI. Приёмник управляет Led1 при превышении верхнего порога и Led2 при значении ниже нижнего порога. В промежуточном диапазоне оба светодиода выключены. Нижний и верхний пороги задаются в исходном коде, при этом нижний порог должен быть меньше верхнего.

<u>Параметры SCI:</u>

Порт SCI: B
Скорость: 4800 бод,
Количество бит данных: 7,
Стоп-бит: 1,
Бит чётности: even;
Таймер: CPU Timer2

---

**Вариант 7:**

Измерять длительность нажатия K1 с разрешением 1 мс. Короткое нажатие (менее 2 с) формирует одну команду, длительное (2 с и более) - другую. При коротком нажатии передавать команду 0x5, при длительном 0xA. Приёмник обрабатывает посылку и изменяет состояние свтодиода Led1 на противоположное при коротком нажатии и Led2 при длинном. Команда отправляется по SCI только после отпускания кнопки, когда длительность уже измерена.

<u>Параметры SCI:</u>

Порт SCI: С
Скорость: 9600 бод,
Количество бит данных: 4,
Стоп-бит: 1,
Бит чётности: odd;
Таймер: CPU Timer2

---

**Вариант 8:**

Изменять коэффициент заполнения мигания светодиода Led1 кнопкой K1. K1 увеличивает коэффициент заполнения на 10 процентных пунктов в диапазоне от 0 до 100%. При превышении 100% последующее нажатие устанавливает скажность в 0. Период мигания светодиода - 2 секунды.
При каждом нажатии K1 выбранное значение коэффициента заполнения передаётся по SCI. После получения значения приёмник устанавливает коэффициент заполнения светодиода Led2 по формуле $D_2 = 100\% - D_1$, 
где ($D_1$) — переданное значение коэффициента заполнения Led1, а ($D_2$) — коэффициент заполнения Led2. Период мигания Led2 также составляет 2 секунды.

<u>Параметры SCI:</u>

Порт SCI: С
Скорость: 38400 бод,
Количество бит данных: 8,
Стоп-бит: 1,
Бит чётности: odd;
Таймер: CPU Timer1

---

**Вариант 9:**

Каждое нажатие K1 увеличивает счётчик событий на единицу. K2 передаёт текущее значение по SCI. После приёма программа включает Led1, если номер события кратен трём, и Led2, если он кратен пяти. Если число кратно обоим значениям, включаются оба светодиода. В иных случаях светодиоды должны быть выключены. Счётчик работает в диапазоне 1–255 с переходом от 255 к 1.

<u>Параметры SCI:</u>

Порт SCI: С
Скорость: 19200 бод,
Количество бит данных: 8,
Стоп-бит: 1,
Бит чётности: odd;
Таймер: CPU Timer0
